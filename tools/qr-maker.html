Bench QR Code Maker

Makes the QR code file to send to the engraver. Use it once the website address is final.

Shorter addresses make simpler codes with bigger squares, which engrave and scan better.

Before you engrave

  • The address is permanent. Metal can't be updated, so the address in the code must work for as long as the bench stands. Own the domain first, and keep it renewed.
  • Print this code on paper at the real size and scan it with a few different phones before sending it out.
  • Ask the engraver for dark squares on a light background with strong contrast, such as black-filled engraving on brushed stainless or anodized aluminum. Shiny bare metal on metal is hard for cameras to read.
  • Keep the blank border around the code. Phones need it to find the edges.
  • Each small square should be at least 0.04 inch (1 mm) so it survives weather. The numbers under the preview tell you where you stand.
  • Ask the engraver not to round, smooth or restyle the squares.
